Browser Permissions, Search Modes & Softphone / SIP / PSTN Routing Notes

1. HTTPS / Localhost, Mic & API Key Privacy

Browsers require a secure context (https:// or http://localhost) and microphone permission for SpeechRecognition. Your Gemini API key is stored only in localStorage in this browser and sent directly to Google's generateContent endpoint with google_search grounding.

2. Routing Audio to Softphone / SIP / PSTN

Web Speech APIs run in the browser tab. To bridge a search-enabled voice bot onto a real softphone, SIP trunk, or PSTN line, route virtual audio cables (e.g., VB-Cable or BlackHole) into your softphone—or connect a backend telephony bridge (Twilio Media Streams, SIP/WebRTC gateway, or Asterisk/FreeSWITCH) to STT, Google Search grounding, and TTS.
