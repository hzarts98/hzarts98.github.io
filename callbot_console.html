Browser Permissions & Softphone / SIP / PSTN Routing Notes

1. HTTPS / Localhost & Mic Permissions

Browsers require a secure context (https:// or http://localhost) and explicit microphone permission for SpeechRecognition. Embedded previews may restrict mic access—use the Send Caller Turn input box whenever testing in a sandboxed frame.

2. Routing Audio to Softphone / SIP / PSTN

Web Speech APIs run in the browser tab. To bridge a bot onto a real softphone, SIP trunk, or PSTN line, route virtual audio cables (e.g., VB-Cable or BlackHole) into your softphone—or connect a backend telephony bridge (Twilio Media Streams, SIP/WebRTC gateway, or Asterisk/FreeSWITCH) to streaming STT/LLM/TTS services.
