Browser Permissions, Local AI Storage & Telephony / Dialer Bridging

HTTPS / Localhost Mic & localStorage AI Keys

Microphone speech recognition requires https:// or http://localhost plus mic permission. Optional API keys in AI Settings are saved only in localStorage for local testing—never put secret keys in public client code or production dialers.

Bridging to Softphone, SIP, PSTN & VICIdial

Browser speech APIs run locally in this tab. To connect into a softphone, SIP trunk, PSTN line, or VICIdial campaign/blind-transfer flow, route virtual audio cables (such as VB-Cable or BlackHole) or hook transfer triggers into a server-side SIP/Asterisk/AMI or WebRTC telephony bridge.
