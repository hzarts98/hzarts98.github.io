Browser Permissions, AI Keys & Softphone / SIP / PSTN Routing Notes

1. HTTPS / Localhost, Mic & Browser AI Keys

Browsers require a secure context (https:// or http://localhost) and microphone permission for SpeechRecognition. Optional API keys in AI Settings are saved only in localStorage for local/testing use—never embed secret API keys in public client apps or production telephony flows.

2. Routing Audio & LLM Calls in Telephony

Web Speech APIs run inside the browser tab. To bridge onto a softphone, SIP trunk, or PSTN line, route virtual audio devices (such as VB-Cable or BlackHole) into your softphone—or run a backend server (Twilio Media Streams, SIP/WebRTC gateway, or Asterisk/FreeSWITCH) that holds your LLM credentials and streams audio/text securely.
